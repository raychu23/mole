# MADR record format

- Fetched: 2026-11-02
- URL: https://github.com/adr/madr
- Primary source: MADR maintainers' upstream repository.
- Relevant behavior: a template is copied to a numbered Markdown record under
  a decisions directory; the project supports templates with YAML front matter.
- T51 fit: render a small Markdown record with the existing Mole front-matter
  keys (`id`, `title`, `status`) and a `## Decision` body. Do not replace the
  wider MADR template or change the existing multi-dialect loader.
