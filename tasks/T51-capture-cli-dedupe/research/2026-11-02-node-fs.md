# Node filesystem primitives

- Fetched: 2026-11-02
- URL: https://nodejs.org/download/release/v14.17.0/docs/api/fs.html
- Primary source: Node.js filesystem documentation.
- Relevant behavior: `rename` overwrites an existing file; `FileHandle.sync()`
  provides `fsync(2)` for a staged file.
- T51 fit: use exclusive creation for new record staging, `sync()` before each
  rename, and prohibit an existing destination from being overwritten unless it
  is an explicit transaction target with an original backup.
